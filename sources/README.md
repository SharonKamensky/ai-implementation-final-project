# Source Materials

This folder contains the material that was **given as part of the course assignment** and used as the input/research base for this project. It was not written by the project author — it is included here only for context, so a reader can see the raw information the diagnosis in [`/docs/step_A_organization_mapping.md`](../docs/step_A_organization_mapping.md) and [`/docs/step_B_bottlenecks.md`](../docs/step_B_bottlenecks.md) was built from.

- **`client_case_file_urbankitchen.md`** — the client case file (in Hebrew, as provided): a simulated set of interviews with people at a fictional company, "UrbanKitchen," representing the discovery research a consultant/implementer would normally conduct before recommending an AI/automation solution. All company names, people and figures in this file — and in the project as a whole — are fictional and were created for the purposes of the course assignment.

Everything else in this repository (the diagnosis, the bottleneck analysis, the solution design, the Make scenario, the KPI framework, the implementation plan and the client presentation) was created by the project author as the deliverable for the assignment.
